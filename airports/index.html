Airport drive times

Driving time

The big number is Google's best estimate for that departure. The bar runs from a light-traffic day to a heavy-traffic day.

Through the day

Best-estimate minutes for leaving on each hour, 5 AM to 11 PM. Uses up to 57 lookups.

Setup and settings
  1. In Google Cloud Console, create a project and turn on billing.
  2. Enable the Routes API.
  3. Under Credentials, create an API key. Restrict it to the Routes API and to the website captainamerica47.github.io/*.
  4. Paste the key below. It is saved only in this browser.
